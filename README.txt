GAS UP — WORK MILEAGE TRACKER

QUICK START
1. Open index.html in a modern browser to log mileage.
2. Add users with '+ User'. Switch users using the dropdown.
3. Enter a trip date, purpose, and miles. Or enter both odometer readings to calculate miles.
4. Choose Day, Week, or Month and pick a date within that period.
5. Download CSV for Excel/Sheets, Download Report for a standalone printable HTML file, Print, or Share.

TO INSTALL ON A PHONE
Host these files on a secure HTTPS site (such as GitHub Pages).
- iPhone Safari: Share > Add to Home Screen.
- Android Chrome: menu > Install app or Add to Home screen.
On a hosted site, the app shell is cached for offline use after first load.

GITHUB PAGES
Create a repository, upload index.html, icon.svg, manifest.webmanifest, and sw.js to repository root.
Under Settings > Pages, choose Deploy from branch > main > /(root).
Open the HTTPS Pages URL after it deploys.

DATA AND PRIVACY
All trip and user information is saved in this browser's local storage. It is NOT synchronized between devices or accounts; profiles are local organizational labels, not password-protected accounts. Browser resets, clearing site data, private browsing, or changing devices can lose the data. Download reports regularly. CSV export covers only the current user and the selected date period. To keep every period, export them separately.

GPS TRIP TRACKING (VERSION 2)
1. Publish the app to HTTPS (e.g. GitHub Pages). GPS is not reliable when opening index.html as a file.
2. On your phone, enter a trip purpose in GPS trip tracker, tap Start trip, and allow location access.
3. Keep the page visible and phone awake while driving. GPS can pause or fail when the screen locks or the app moves to the background.
4. Tap End & save to record the estimated miles under the selected user, or Discard to delete the in-progress trip.
5. If the page reloads or the browser restarts, an interrupted trip can be resumed manually. Mileage while inactive cannot be recovered.
GPS distance uses consecutive accurate location fixes and rejects very short movements and unrealistic jumps. It may undercount when signals are weak, and it should not be treated as certified odometer data. For reimbursement, verify mileage and edit your record if necessary. Manual mileage entry remains available.
Only one GPS trip can be active per browser. A user cannot be switched while a GPS trip is in progress. GPS samples remain on the device, and only the distance and summary are saved as a trip record.
 Actual employer reimbursement and tax eligibility rules may differ; verify trip entries and required documentation.
