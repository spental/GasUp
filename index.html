Connect Gas Up to Supabase

Cloud saving requires your own free Supabase project. This download includes the database schema and setup guide.

1. Create a Supabase project.
2. Run schema.sql in the SQL Editor.
3. Put your Project URL and publishable/anon key in config.js.
4. Publish these files on GitHub Pages (HTTPS).

Never add a Supabase service_role key or secret key to config.js. Users can only access their own records once the included row-level security rules are installed.
